Конвертор температур.

Конвертирует температуру из одного измерения в другое измерение: цельсия, фаренгейт, кельвин.

Разработан с помощью такого языка программирования как Golang.

Для того, чтобы запустить программу непосредственно в VScode выполните команду в терминале (View-terminal) go run main.go.
